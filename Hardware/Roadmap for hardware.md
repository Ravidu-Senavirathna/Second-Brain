CPU - Designed for fast, flexible execution of instructions. It handles operating systems, applications, logic, and complex control flows.
GPU - Designed to perform many computations in parallel. It is particularly useful for graphics, scientific computing, and AI.

Main fundamental concepts to learn.

| Concept          | What you'll learn                         |
| ---------------- | ----------------------------------------- |
| Binary           | How computers represent data              |
| Logic gates      | AND, OR, NOT, XOR                         |
| Transistors      | The building blocks of processors         |
| Registers        | Very fast storage inside CPUs             |
| ALU              | Arithmetic and logical operations         |
| Clock            | How processor operations are synchronized |
| Memory hierarchy | Registers, cache, RAM, storage            |
| Instructions     | How software communicates with hardware   |

## 4. Understand CPU vs GPU

|Feature|CPU| GPU                               |
|---|---|---|
|Main focus|Low-latency execution| High-throughput execution         |
|Cores|Relatively few powerful cores| Many processing units             |
|Control logic|Complex| Often simpler per processing unit |
|Parallelism|Limited compared with GPUs| Massive parallelism               |
|Cache|Large emphasis on low latency| Often optimized for throughput    |
|Best suited for|General computing| Parallel workload
